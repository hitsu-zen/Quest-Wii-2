# Quest-Wii-2

Welcome to Quest Wii 2, the development kit of Toadiko into Yamato for New Super Mario Bros Wii!

What you can find here :

 - .PSD (Photoshop) files used for the creation of the tilesets of the mod.
 - Source code of the new features.
 - .kpmap (Koopatlas Map) file of the worldmap of Yamato.
 - Tileset files used in the worldmap.
 - Reggie spritedata.xml to use the new features in your levels.
